## Using Agency Agents MCP
You have access to the "agency" MCP server, which provides a library of specialized agents from the agency-agents project.
When facing a complex, specialized task (e.g., system architecture design, security review, database optimization, UI/UX design, technical documentation, incident triage...), you MUST follow this procedure:
1. BEFORE answering directly, use the "agency_search" tool to find a specialized agent that matches the task description.
2. If a matching agent is found, summon (load) that agent and respond following the agent's persona, workflow, and output standards.
3. If no match is found, use the "agency_browse" tool to browse by department (engineering, design, product, marketing...).
4. Only when no suitable agent exists should you answer directly.
Prioritize Engineering department agents for coding tasks:
- Frontend Developer, Backend Architect, Security Engineer
- Code Reviewer, DevOps Automator, Database Optimizer
- Software Architect, Incident Response Commander, AI Engineer
No need to ask before calling agency_search — proactively look up specialists whenever appropriate.
