# PHP Impact Unittest Loop - Commands

Runnable command reference for the `php-impact-unittest-loop` skill. Copy-paste directly into a terminal at the project root.

## 1. Identify changed files and functions (git diff)

```bash
git status --short
git diff --name-only HEAD
git diff -U0 HEAD -- '*.php'
```

Filter source files only, skipping old tests:

```bash
git diff --name-only HEAD -- 'src/*.php' 'app/*.php'
```

Show the method containing the changed lines (e.g. checking `src/Service/OrderService.php`):

```bash
git diff -U0 HEAD -- src/Service/OrderService.php
grep -n "function " src/Service/OrderService.php
```

## 2. Check the PHP coverage environment

```bash
php -v
php -m | grep -Ei "pcov|xdebug"
vendor/bin/phpunit --version
```

If the coverage driver is missing, install one of:

```bash
pecl install pcov
php -d pcov.enabled=1 -m | grep pcov
```

```bash
php -m | grep xdebug
XDEBUG_MODE=coverage php -v
```

## 3. Run selective PHPUnit with filter

Run 1 test class:

```bash
vendor/bin/phpunit --filter OrderServiceTest
```

Run 1 specific test method:

```bash
vendor/bin/phpunit --filter "OrderServiceTest::testCalculateTotalReturnsCorrectValue"
```

Run multiple classes in 1 directory:

```bash
vendor/bin/phpunit --filter "OrderServiceTest|PaymentServiceTest"
vendor/bin/phpunit tests/Unit/Service/OrderServiceTest.php
```

## 4. Run with coverage (clover + html)

Using PCOV (fast, recommended locally):

```bash
php -d pcov.enabled=1 vendor/bin/phpunit --filter OrderServiceTest --coverage-clover clover.xml --coverage-html coverage/
```

Using Xdebug (when PCOV is unavailable):

```bash
XDEBUG_MODE=coverage vendor/bin/phpunit --filter OrderServiceTest --coverage-clover clover.xml --coverage-html coverage/
```

Run the full suite when the impact is wide (with user confirmation):

```bash
php -d pcov.enabled=1 vendor/bin/phpunit --coverage-clover clover.xml --coverage-html coverage/
```

## 5. Read and filter clover.xml by changed method

Real Clover structure generated by php-code-coverage (sample source: https://raw.githubusercontent.com/sebastianbergmann/php-code-coverage/main/tests/_files/Report/Clover/BankAccount-line.xml):
- The root `<coverage>` tag contains `<project>` with many `<file name="...">` entries (namespaced ones are wrapped in `<package name="...">`).
- Each `<file>` contains `<class name="..." namespace="...">`, `<line num type name count>` entries, and one direct-child `<metrics>` at the end of the file.
- There is no dedicated `<method>` tag: a method is `<line type="method" name="MethodName" count="...">` (count above 0 means covered). A statement is `<line type="stmt" count="...">`.
- File ratios live in `<metrics statements coveredstatements methods coveredmethods>` as a direct child of `<file>`.
- PCOV gives line coverage only; use Xdebug for branch/path coverage.

Show the metrics overview:

```bash
grep -o '<metrics[^>]*>' clover.xml | head -n 5
```

Filter metrics for one file (use the direct-child `/metrics` to avoid colliding with `<class>`-level metrics):

```bash
grep -A2 'name=".*OrderService.php"' clover.xml
php -r '$x = simplexml_load_file("clover.xml"); foreach ($x->xpath("//file[contains(@name,\"OrderService.php\")]/metrics") as $m) { echo $m->asXML(), PHP_EOL; }'
```

List uncovered lines (count=0) in the changed file:

```bash
php -r '$x = simplexml_load_file("clover.xml"); foreach ($x->xpath("//file[contains(@name,\"OrderService.php\")]/line[@count=\"0\"]") as $l) { echo $l["num"], ":", $l["type"], PHP_EOL; }'
```

List per-method cover status in the changed file (a method is a line with type=method):

```bash
php -r '$x = simplexml_load_file("clover.xml"); foreach ($x->xpath("//file[contains(@name,\"OrderService.php\")]/line[@type=\"method\"]") as $l) { $c = (int)$l["count"]; printf("%s count=%d %s\n", $l["name"], $c, $c > 0 ? "COVERED" : "UNCOVERED"); }'
```

Compute statement % for 1 file (read file-level metrics only):

```bash
php -r '$x = simplexml_load_file("clover.xml"); foreach ($x->xpath("//file[contains(@name,\"OrderService.php\")]/metrics") as $m) { $s=(int)$m["statements"]; $c=(int)$m["coveredstatements"]; printf("statements=%d covered=%d pct=%.1f%%\n", $s, $c, $s ? $c*100/$s : 100); }'
```

Compute statement % for 1 specific method (count stmt lines from that method to the next one, e.g. method calculateTotal):

```bash
php -r '$f = "OrderService.php"; $target = "calculateTotal"; $x = simplexml_load_file("clover.xml"); foreach ($x->xpath("//file[contains(@name,\"" . $f . "\")]") as $file) { $in = false; $s = 0; $c = 0; $miss = []; foreach ($file->line as $l) { if ((string)$l["type"] === "method") { if ($in) { break; } if ((string)$l["name"] === $target) { $in = true; } } elseif ($in && (string)$l["type"] === "stmt") { $s++; if ((int)$l["count"] > 0) { $c++; } else { $miss[] = (int)$l["num"]; } } } printf("method=%s statements=%d covered=%d pct=%.1f%%\n", $target, $s, $c, $s ? $c*100/$s : 100); if ($miss) { echo "uncovered lines: " . implode(",", $miss) . PHP_EOL; } }'
```

## 6. Open the HTML report interactively

```bash
ls coverage/index.html
```

Open on Windows (PowerShell):

```powershell
start coverage/index.html
```

Open on macOS / Linux:

```bash
open coverage/index.html
xdg-open coverage/index.html
```

Serve the coverage directory for browser viewing:

```bash
php -S 127.0.0.1:8000 -t coverage/
```

## 7. Archive evidence as ZIP when done

Create the ZIP exactly once on success or final stop. Create the `evidence` directory if missing:

```bash
mkdir -p evidence
zip -r evidence/php-final-coverage.zip clover.xml coverage/
```

Windows PowerShell (if the zip command is missing):

```powershell
New-Item -ItemType Directory -Force -Path evidence
Compress-Archive -Path clover.xml,coverage -DestinationPath evidence/php-final-coverage.zip -Force
```

Verify the newly created ZIP:

```bash
ls -lh evidence/php-final-coverage.zip
unzip -l evidence/php-final-coverage.zip | head -n 20
```
